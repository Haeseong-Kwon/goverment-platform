# startuppilot.co.kr 연결과 검색 등록

가비아에서 산 도메인을 Vercel 배포에 붙이고, 검색·트래킹을 켜는 순서입니다.
**순서가 중요합니다.** 도메인을 붙이기 전에 검색 등록을 하면 vercel.app 주소가 색인되어 나중에 정리해야 합니다.

---

## 1단계 — Vercel에 도메인 추가

Vercel 프로젝트 → **Settings → Domains → Add**

1. `startuppilot.co.kr` 추가
2. `www.startuppilot.co.kr` 추가 → **Redirect to `startuppilot.co.kr`** 선택
   (둘 다 서비스하면 같은 내용이 두 주소로 색인됩니다. 하나로 모읍니다.)
3. `startuppilot.co.kr`을 **Primary Domain**으로 지정

Primary로 지정하면 Vercel이 `*.vercel.app` 주소를 이 도메인으로 308 리다이렉트합니다.
기존 배포 주소가 검색에 남는 문제가 이걸로 정리됩니다.

Vercel이 화면에 보여주는 DNS 값을 그대로 쓰세요. 아래 값은 참고용이며 **화면에 표시된 값이 우선**입니다.

---

## 2단계 — 가비아 DNS 설정

가비아 → **My가비아 → 서비스 관리 → 도메인 → DNS 관리툴 → DNS 설정**

`.co.kr`은 CNAME을 루트(`@`)에 쓸 수 없습니다. 루트는 A 레코드로 지정합니다.

**Vercel이 화면에 보여주는 값을 그대로 쓰세요.** Vercel은 A 레코드 IP와 CNAME 대상을 계속 바꾸며,
CNAME은 프로젝트마다 다른 값을 줍니다. 아래는 2026-07 기준 실제 적용된 값의 예시입니다.

| 타입 | 호스트 | 값 (예시 — 화면 값 우선) | TTL |
|------|--------|--------------------------|-----|
| A | `@` | `216.198.79.1` | 3600 |
| CNAME | `www` | `4f4b3c50a30fdee2.vercel-dns-017.com.` | 3600 |

- 가비아 입력창에서 CNAME 값 끝에 **마침표(`.`)** 를 붙여야 하는 경우가 있습니다. 저장 후 표시된 값을 확인하세요.
- 기존에 가비아 기본 파킹/포워딩 레코드가 있으면 **삭제**합니다. 남아 있으면 간헐적으로 파킹 페이지가 뜹니다.
- 반영까지 보통 10분~1시간, 최대 24시간입니다. Vercel Domains 화면이 `Valid Configuration`으로 바뀌면 끝입니다.

확인 명령:

```bash
dig +short startuppilot.co.kr A; dig +short www.startuppilot.co.kr CNAME
```

## 3단계 — 환경변수 (Vercel → Settings → Environment Variables)

**Production**에 넣습니다. 이 값이 canonical·OG·sitemap의 기준이 됩니다.

```
NEXT_PUBLIC_SITE_URL=https://startuppilot.co.kr
```

같이 확인할 것 — **Supabase 인증이 이 값을 씁니다.**
Supabase Dashboard → Authentication → URL Configuration:

- Site URL: `https://startuppilot.co.kr`
- Redirect URLs에 추가: `https://startuppilot.co.kr/auth/callback`, `https://startuppilot.co.kr/auth/reset`

이걸 안 바꾸면 도메인을 붙인 뒤 **가입 인증 메일 링크가 예전 주소로 갑니다.**

## 4단계 — 검색 등록 (도메인이 붙은 뒤에)

### Google Search Console
1. <https://search.google.com/search-console> → 속성 추가 → **URL 접두어**로 `https://startuppilot.co.kr`
2. 소유 확인은 **HTML 태그** 방식 선택 → `content="..."` 안의 값만 복사
3. Vercel 환경변수에 `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=<값>` 추가 → 재배포 → 확인 누르기
4. 확인 후 **Sitemaps**에 `sitemap.xml` 제출

### 네이버 서치어드바이저 (국내 유입의 핵심)
1. <https://searchadvisor.naver.com> → 웹마스터도구 → 사이트 등록
2. 소유 확인 **HTML 태그** 방식 → `content` 값만 복사
3. `NEXT_PUBLIC_NAVER_SITE_VERIFICATION=<값>` 추가 → 재배포 → 확인
4. **요청 → 사이트맵 제출**에 `https://startuppilot.co.kr/sitemap.xml`
5. **요청 → 웹페이지 수집**으로 주요 3개 주소를 수동 수집 요청 (네이버는 자동 수집이 느립니다)

### 다음(카카오)
<https://register.search.daum.net/index.daum> 에서 주소만 등록하면 됩니다. 별도 태그가 없습니다.

## 5단계 — 트래킹 켜기

값을 넣은 것만 동작합니다. 비워 두면 스크립트가 아예 삽입되지 않습니다.
**로컬·프리뷰에서는 자동으로 꺼집니다**(프로덕션 빌드에서만 동작).

| 환경변수 | 어디서 받나 | 왜 필요한가 |
|----------|-------------|-------------|
| `NEXT_PUBLIC_GA_ID` | GA4 → 관리 → 데이터 스트림 → 웹 (`G-XXXXXXXXXX`) | 유입 경로·전환 기본 측정 |
| `NEXT_PUBLIC_NAVER_ANALYTICS_ID` | 네이버 애널리틱스 사이트 등록 후 발급 | 국내 유입은 네이버 비중이 커서 GA만으로는 안 보입니다 |
| `NEXT_PUBLIC_CLARITY_ID` | <https://clarity.microsoft.com> (무료) | 세션 리플레이·히트맵. 온보딩 이탈 지점을 눈으로 봅니다 |

### 아직 넣지 않은 것 (광고를 시작할 때 추가)

지금은 넣지 않았습니다. 광고를 돌리지 않는 동안은 순수 부하이고, 동의 없이 켜면 법적 문제가 됩니다.

- **Meta(페이스북·인스타그램) 픽셀**, **카카오모먼트 픽셀**, **네이버 전환 추적**
- 필요해지면 `src/components/analytics/Analytics.tsx` 에 같은 패턴(환경변수 있을 때만 `<Script>`)으로 추가하면 됩니다.

### 인증 메일 발송

Supabase 내장 메일은 테스트용 한도라 실사용 전에 커스텀 SMTP로 바꿔야 합니다.
SMTP 연결과 SPF·DKIM·DMARC 설정은 [이메일-발송-설정.md](이메일-발송-설정.md)에 정리했습니다.

### 먼저 처리해야 할 것 — 개인정보 처리방침과 동의

지금 설정은 **광고용 저장소를 기본 거부**(Consent Mode v2)로 두고 분석만 켠 상태입니다.
광고 픽셀을 붙이는 시점에는 아래가 먼저 필요합니다.

- 개인정보 처리방침 페이지 (수집 항목·목적·보유기간·위탁 업체 명시)
- 행태정보 광고 활용에 대한 동의 획득 수단(동의 배너)

현재 코드에는 동의 배너가 없습니다. 제품 결정이 필요한 부분이라 임의로 만들지 않았습니다.

## 6단계 — 붙인 뒤 확인

```bash
curl -s https://startuppilot.co.kr/robots.txt | head -5
curl -s https://startuppilot.co.kr/sitemap.xml | grep -o '<loc>[^<]*</loc>'
curl -sI https://startuppilot.co.kr/opengraph-image | grep -i 'content-type\|content-length'
curl -s https://startuppilot.co.kr/ | grep -o '<link rel="canonical" href="[^"]*"'
```

- `robots.txt`가 `Disallow: /` 한 줄만 보이면 `VERCEL_ENV`가 production이 아닙니다(프리뷰 주소를 본 것).
- canonical이 `https://startuppilot.co.kr` 이 아니면 `NEXT_PUBLIC_SITE_URL`을 확인하세요.

공유 카드 미리보기 점검:

- 카카오톡: <https://developers.kakao.com/tool/debugger/sharing> (캐시가 오래 남으므로 여기서 초기화)
- 페이스북: <https://developers.facebook.com/tools/debug/>
- 구조화 데이터: <https://search.google.com/test/rich-results>

## 생성형 검색(GEO) 관련해서 해둔 것

- `robots.txt`에서 GPTBot·ClaudeBot·PerplexityBot·OAI-SearchBot을 **허용**했습니다(공개 페이지만).
  학습 이용을 원치 않으면 `src/app/robots.ts`의 `AI_CRAWLERS`를 disallow로 바꾸면 됩니다.
- `/llms.txt`에 서비스 정의·기능·주의사항을 요약해 두었습니다. AI가 "심사 도구"로 잘못 소개하지 않도록
  판정 권한이 주관기관에 있다는 문장을 명시했습니다.
- FAQ를 화면과 JSON-LD(`FAQPage`)에 **같은 문장으로** 넣었습니다. 구조화 데이터에만 있는 FAQ는
  검색엔진 정책 위반이라 인용 근거가 되지 못합니다.
- `SoftwareApplication`에 무료 범위를 `offers`로 명시해, 요금을 임의로 추측당하지 않게 했습니다.
